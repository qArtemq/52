# Видео на Google Диске + сайт на обычном хостинге

Сайт весит мало (HTML, CSS, JS, картинки карт). Видео (~7 ГБ) остаются на Google Диске и не заливаются на хостинг.

## 1. Папка на Google Диске

1. Откройте [Google Диск](https://drive.google.com).
2. Создайте папку, например `52 на 9 видео`.
3. Внутри сделайте три подпапки с теми же именами, что локально:
   - `Медиа_52_на_9`
   - `9 MOON`
   - `Массаж`
4. Загрузите туда все `.mp4` из этих папок на компьютере.
5. Для **каждого** видео: ПКМ → **Открыть доступ** → «Все, у кого есть ссылка» → **Читатель** → Готово.  
   Можно сразу открыть доступ на всю родительскую папку — тогда новые файлы тоже будут доступны по ссылке.

## 2. Вписать ID файлов в приложение

1. Откройте файл `video_sources.js` в блокноте или VS Code.
2. Для каждого ролика откройте его на Диске и скопируйте ссылку вида:
   `https://drive.google.com/file/d/1AbCDefGhijKLMnOp/view?usp=sharing`
3. Кусок между `/d/` и `/view` — это **ID**. Вставьте его в кавычки:

```js
'Медиа_52_на_9/РАЗБОР ТЕХНИКИ КАРТ 1-3.mp4': '1AbCDefGhijKLMnOp',
```

4. Сохраните файл. Локально приложение по-прежнему берёт видео с диска, пока ID пустой; после заполнения — с Диска.

Список всех слотов — в `video_sources.js` (около 41 файла).

## 3. Большие ролики массажа (>100 МБ)

Без ключа Google часто показывает страницу «файл слишком большой для проверки на вирусы» вместо видео.

Бесплатный API-ключ:

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект (или выберите существующий).
3. **APIs & Services** → **Library** → найдите **Google Drive API** → **Enable**.
4. **Credentials** → **Create credentials** → **API key**.
5. (Желательно) ограничьте ключ только Drive API.
6. Вставьте ключ в начало `video_sources.js`:

```js
const GOOGLE_API_KEY = 'ваш_ключ_сюда';
```

Квота бесплатная и для личного использования обычно хватает.

## 4. Что выкладывать на хостинг

**Нужно залить:**

- `index.html`
- `app.js`
- `style.css`
- `massage_data.js`
- `moons_data.js`
- `video_sources.js` (уже с заполненными ID)
- `manifest.json`, `favicon.ico`, `icon.png`, `apple-touch-icon.png`
- папку `images/` (картинки карт)
- файл `9 MOON/[SW.BAND] 12.jpg` (одна маленькая картинка)

**Не нужно заливать:**

- папки `Медиа_52_на_9/`, `Массаж/`, `9 MOON/*.mp4`
- `cloudflare/`, `_Исходники_и_скрипты/`, `profiles.json`, `launcher.pyw`, `start.bat`

Удобно: запустите `pack_for_hosting.ps1` — он соберёт папку `hosting_upload` без тяжёлых видео.

Подходящие бесплатные хостинги для такого сайта: Netlify Drop, Cloudflare Pages, GitHub Pages, любой обычный хостинг со статикой.

## 5. Проверка

1. Откройте сайт с хостинга.
2. Карты → нажмите карту: видео должно стартовать с нужного момента.
3. 9 Луны и Массаж — ролики должны открываться.
4. Если чёрный экран: проверьте доступ «по ссылке» и что ID совпадает; для массажа — API-ключ.

## Важно про карты

Для карт нужна перемотка на секунду внутри длинного ролика. Google Диск это умеет не всегда идеально. Если карта стартует с начала или долго буферизуется — сначала заполните ID карт и API-ключ, проверьте ещё раз. Локально через `start.bat` перемотка работает как раньше.
